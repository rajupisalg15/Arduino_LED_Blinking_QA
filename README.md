# Arduino LED Blinking - GitHub QA Activity

## Objective
Create a basic embedded project and use GitHub for QA issue tracking,
root-cause analysis, collaboration, commits, testing, and resolution.

## Hardware
- Arduino Uno or compatible board
- Built-in LED (or external LED + 220 ohm resistor)
- USB cable

## Software
- Arduino IDE
- GitHub

## Expected Result
LED ON for 1 second, then OFF for 1 second, continuously.

## QA Issues
1. LED not blinking
2. LED always ON
3. Incorrect blinking speed
4. External LED not working

## GitHub Workflow
Issue -> Root Cause -> Fix -> Commit -> Test -> Close Issue

Replace the repository link in your report after creating the GitHub repository.
